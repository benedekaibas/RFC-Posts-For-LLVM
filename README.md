# RFC Posts for LLVM
 
This repository contains RFC post materials that I have been posting on the [LLVM Discourse](https://discourse.llvm.org/).
 
## Why write LLVM RFC posts?
 
Writing LLVM RFC posts has many benefits:
 
- You can share your work, idea, etc. with experienced developers within LLVM
- You can get feedback on your RFC from more experienced devs
- Cases you did not think about might be raised here
- You will be challenged by top tier developers
- It's fun
## About this repository
 
This repository contains the notes, drafts, and ideas that I have for different RFCs.
 
If you find it useful, feel free to use any of the materials here, but note that some of them are just basic brainstorming notes.
